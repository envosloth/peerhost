                          Advanced: Java and custom arguments
            
                          
              
                          1
                          The runtime that starts your server.
                          
              
              
                          
            
                          
            
            
            
                          Example: ["-XX:+UseG1GC", "-XX:MaxGCPauseMillis=200", "-Dmy.setting=value"]. Each string is one JVM argument, never a shell command. Heap, launcher, classpath, argument files, agents and executable hooks are blocked. Unsupported imported options are retained; use advanced launch settings to change those. RAM-only saves keep your existing arguments.
