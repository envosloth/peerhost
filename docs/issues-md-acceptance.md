## Quality gates

- Test-first failing regressions before behavior changes; record RED/GREEN output.
- Run the latest-source canonical baseline, then compare named failures, not only totals.
- Build/typecheck the combined code, test security boundaries and error cases, and run visible actual Electron input checks against the combined build.
- Have an independent reviewer examine the complete diff and fix material findings.
- Package and exercise the actual deliverable; do not mark deployed/network acceptance as verified without evidence.
- Preserve the original issue prose, updating checkboxes only for verified completion with an accompanying evidence report.
